# Apex 50K v2.6 — System crontab entry
#
# Three options for system-level cron on a 24/7 host:
#
# 1) Single daily fire (13:00 UTC = 21:00 SHA = 09:00 EDT)
#    Install with: crontab -e, then paste the line below

0 13 * * * /workspace/apex-bootcamp/AUTOMATION/cron_runner.sh >> /var/log/apex-cron.log 2>&1

#
# 2) Two fires (09:00 UTC = 17:00 SHA early, 13:00 UTC = 21:00 SHA target)
#    Slightly more load on LLM API, but catches missed first fire
#    Install with: crontab -e, then paste the lines below

# 0 9  * * * /workspace/apex-bootcamp/AUTOMATION/cron_runner.sh >> /var/log/apex-cron.log 2>&1
# 0 13 * * * /workspace/apex-bootcamp/AUTOMATION/cron_runner.sh >> /var/log/apex-cron.log 2>&1

#
# 3) Self-restart loop (no system cron needed)
#    Best for sandboxes without cron support
#    Run once: nohup /workspace/apex-bootcamp/AUTOMATION/cron_runner.sh > /var/log/apex-cron.log 2>&1 &
#    It auto-respawns at 13:00 UTC daily.
#    Kill with: pkill -f cron_runner.sh
#
# The crontab.txt is documentation — to install, copy the line above to your crontab.
