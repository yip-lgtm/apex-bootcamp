## 快速開始

1. 每天開盤前打開 **[CHECKLIST.md](./CHECKLIST.md)**
2. 按順序執行，只做 **A 級（2+2）** Setup
3. 收盤後按 **chart-standards** 截至少 3 張圖並填寫日誌

- 時區統一 **UTC-4**
