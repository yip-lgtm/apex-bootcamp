# Apex 50K 規則

## 官方核心參數

| 項目 | 數值 |
|------|------|
| **Profit Target** | $3,000 |
| **Max Drawdown** | $2,000 (Intraday Trail) |
| **Max Contracts** | 2 Micro（個人限制，官方通常更高） |
| **Daily SL Kill-switch** | $100（個人硬限制） |
| **合格獲利日** | 至少 5 天（單日淨利 ≥ $250 才算 1 天） |
| **Min Days To Pass** | 5 |
| **Scaling** | Built-in for PA |

## 個人硬限制（必須遵守）

1. **Max Contracts ≤ 2 Micro**  
   超過即違規，立即停止。

2. **Daily SL Kill-switch = $100**  
   當日淨虧損達到 $100，強制平倉，當天不再進場。

3. **只做 A 級 Setup**  
   B 級可減倉謹慎做，C 級直接跳過。

4. **不隔夜**  
   所有倉位必須在當日收盤前平掉（依 Apex 規則）。

5. **Bracket Order 強制**  
   進場必須同時設置 SL + TP，不留裸倉。

---

*違反以上任何一條 = 當日交易結束。*
