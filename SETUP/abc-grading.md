# A / B / C 計分系統

用 **主動 + 被動 + 工程 + 預設** 四個元素計分。

## 計分方式

| 等級 | 定義 | 執行方式 |
|------|------|----------|
| **A** | **2+2**（四個元素全有） | **正常倉位執行** |
| **B** | **2+1 / 1+2**（三個元素） | **減倉 / 更緊 SL** |
| **C** | **1+1**（兩個元素） | **禁止交易** |

## 執行優先順序

1. 先確認左右環境
2. 再數主動 / 被動 / 工程 / 預設 有幾個
3. 對應 A / B / C 決定是否下單及倉位大小

**Apex 50K 建議：只優先做 A 級。**
