# 交易日誌圖表標準（v1.0）

**必須至少 3 張圖**。  
更小周期畫的東西不要顯示在更高周期上，保證美觀簡潔。  
時區統一 **UTC-4**。

---

## 圖 1｜HTF-D（日線）

必須標記：
1. **周開盤價 (Wo)**
2. **程序的起點** 和 **終點**
3. 用豎線標記**你的交易日**是哪一天

**示例重點**：Wo + 程序起點/終點 + 交易日豎線

---

## 圖 2｜LTF-H4

必須標記：
1. **日開盤價 (DO)**
2. 啟動時間視角
3. 標記你交易的 **H4 蠟燭**是哪一根
4. **左側環境**（沒有就跳過）
5. **右側環境**（沒有就跳過）
6. **極點環境**：主動 + 被動 + 工程 + 預設

**示例重點**：DO + 左側/右側 + 極點環境

---

## 圖 3｜LTF-H1

必須標記：
1. **日開盤價 (DO)**
2. 啟動時間視角
3. **紅綠燈階段**
4. **左側環境**
5. **右側環境**
6. **極點環境**：主動 + 被動 + 工程 + 預設

**示例重點**：DO + 紅綠燈 + 環境標記  
> H1 沒有特殊補充就不需要寫（H4 已能識別時可跳過）。

---

## 報告欄位（v1.0）

| 欄位 | 說明 |
|------|------|
| chartHTF | HTF-D 是否完成 |
| chartH4 | H4 是否完成 |
| chartH1 | H1 是否完成 / 可跳過 |
| chartsOk | ≥3 張圖是否已備妥 |
| llmRemark | LLM 二次判斷的文字理由 |
