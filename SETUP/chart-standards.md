# 交易日誌圖表標記標準

**必須至少 3 張圖**。  
更小周期畫的東西不要顯示在更高周期上，保證美觀簡潔。  
時區統一 **UTC-4**。

---

## 圖 1｜HTF-D（日線）

必須標記：
1. **周開盤價 (Wo)**
2. **程序的起點** 和 **終點**
3. 用豎線標記**你的交易日**是哪一天

**示例重點**：Wo + 程序起點/終點 + 交易日豎線

---

## 圖 2｜LTF-H4

必須標記：
1. **日開盤價 (DO)**
2. 啟動時間視角
3. 標記你交易的 **H4 蠟燭**是哪一根
4. **左側環境**（沒有就跳過）
5. **右側環境**（沒有就跳過）
6. **極點環境**：主動 + 被動 + 工程 + 預設

**示例重點**：DO + 左側/右側套殺 + 極點環境（主動+被動+工程）

---

## 圖 3｜LTF-H1

必須標記：
1. **日開盤價 (DO)**
2. 啟動時間視角
3. **紅綠燈階段**
4. **左側環境**
5. **右側環境**
6. **極點環境**：主動 + 被動 + 工程 + 預設

**示例重點**：DO + 紅綠燈 + 「H1 沒有特殊補充就不需要寫」

> **注意**：H1 沒有特殊補充就不需要寫，因為 H4 可以識別到所有環境。  
> 如果 H4 沒有環境，才要在 H1 上畫出環境。
