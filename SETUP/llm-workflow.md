# 規則初篩 + LLM 二次判斷 工作流程

適用於套杀、SMT、左右環境等難以完全程式化的邏輯。

---

## 流程總覽

```
1. 規則初篩（Pine Script）
        ↓
2. 產生候選訊號
        ↓
3. 截圖 + 結構化資訊
        ↓
4. 丟給 LLM 做二次判斷
        ↓
5. LLM 回覆 A/B/C + 理由
        ↓
6. 你最終決定是否進場
```

---

## 第一步：規則初篩（程式負責）

程式只做客觀過濾，不負責最終判斷。

**必須滿足：**
- 在 Killzone 時間內
- 出現基本掃單（Sweep）
- 當日尚未觸及 Daily SL $100
- 目前沒有持倉

滿足條件就標記「候選訊號」。

---

## 第二步：準備給 LLM 的資訊

### 必備 3 張圖
1. **HTF-D**：Wo、程序起點/終點、交易日豎線
2. **H4**：DO、掃單位置、左右環境
3. **H1 / 進場週期**：掃單細節、Displacement

### 文字模板（直接複製）

```
【候選訊號】
品種：MNQ
時間：YYYY-MM-DD HH:MM (NY)
方向：做多 / 做空
週期：5m / 15m

掃單情況：
- 掃的是前高還是前低？
- 掃了多少點？
- 收盤是否收回？

目前觀察到的環境：
- 左側環境：
- 右側環境：
- 主動 / 被動 / 工程 / 預設：有 / 無

其他備註：
```

---

## 第三步：LLM 二次判斷

把圖 + 文字貼給 LLM 後，預期回覆格式：

```
【LLM 判斷結果】
最終等級：A / B / C
建議動作：進場 / 觀望 / 放棄

理由：
1. ...
2. ...
3. ...

風險提示：
- ...
```

---

## 第四步：最終決策規則

| LLM 等級 | 建議動作 |
|----------|----------|
| **A** | 優先考慮進場（正常倉位） |
| **B** | 可做，但減倉或更緊止損 |
| **C** | 直接跳過 |

仍須遵守：
- Daily SL $100
- 最多 1 張 MNQ
- Bracket Order

---

## 執行節奏

| 階段 | 負責 | 工具 |
|------|------|------|
| 初篩 | 程式 | Pine Script |
| 截圖 + 填模板 | 你 | TradingView + Notion |
| 二次判斷 | LLM | Grok |
| 最終決定 + 下單 | 你 | 手動 |
| 複盤 | 你 + LLM | Notion 日誌 |
