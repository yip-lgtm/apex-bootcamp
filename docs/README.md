# Apex 50K 線上績效儀表板

## 開啟 GitHub Pages 後的網址

```
https://yip-lgtm.github.io/apex-bootcamp/
```

## 功能

- 新增每日 PnL / 交易數 / 盈利數 / RR / 等級
- 自動計算累計 PnL、勝率、合格獲利日
- 資料存在瀏覽器 localStorage（不會上傳到伺服器）
- 可匯出 JSON 或 Markdown（方便貼回 GitHub）

## 如何開啟 GitHub Pages

1. 打開 https://github.com/yip-lgtm/apex-bootcamp/settings/pages
2. Source 選擇 **Deploy from a branch**
3. Branch 選 `main`，資料夾選 `/docs`
4. 按 Save
5. 約 1 分鐘後即可用上面的網址開啟
